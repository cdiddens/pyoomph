Advanced stability analysis
===========================

In this section, we cover some advanced topics on linear stability analysis, i.e. stability analysis of moving meshes and stability analysis of axisymmetric base states subject to azimuthal perturbations. Also, the linear response to periodic driving is discussed. We start, however, with the interactive bifurcation GUI, which is a different way of arriving at a bifurcation diagram: not by writing the continuation down in advance, but by steering it while it runs.
